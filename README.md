# QA ARTIFACTS
## Vendor Invoice Management Portal

## Problem Statement

The **Vendor Invoice Management Portal** is a B2B web application designed to streamline the invoice lifecycle between external vendors and an internal Accounts Payable (AP) team. The system must support:

- Secure vendor self-registration and role-based login
- Submission of invoices linked to Purchase Orders (POs), including file attachments
- A multi-step AP workflow for reviewing, approving, or rejecting invoices
- Automated forwarding of approved invoices to the payment processing system
- Email notifications to both vendors and AP staff on status changes
- Monthly reporting and data export for management oversight
- Strict Role-Based Access Control (RBAC) to prevent unauthorized data access

The QA objective is to validate all 7 functional requirements end-to-end across UI, API, and database layers — ensuring correctness, security, performance, and data integrity before the system goes live.
