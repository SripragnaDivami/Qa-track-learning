## 7.2 Sample Bug Reports

### BUG-001: Invoice Submission — Vendor Can Submit Without Attaching an Invoice File

| Field | Details |
|-------|---------|
| **Bug ID** | BUG-001 |
| **Title** | Invoice Submission — Vendor can submit invoice form without attaching a file |
| **Environment** | QA \| Chrome 126 \| Windows 11 \| Build 2.3.1 |
| **Severity** | High |
| **Priority** | P1 |
| **Reproducibility** | Always |
| **Preconditions** | Vendor V001 logged in. PO-1001 is open. |
| **Steps to Reproduce** | 1. Navigate to Submit Invoice<br>2. Enter all mandatory text fields with valid data<br>3. Do NOT attach any file<br>4. Click Submit |
| **Expected Result** | Validation error: 'Invoice file attachment is required.' Form is not submitted. |
| **Actual Result** | Invoice is submitted successfully with status 'Pending Review' despite no file being attached. Invoice record shows blank file attachment. |
| **Attachments** | screenshot_bug001.png, api_response_bug001.json |

### BUG-002: Access Control — Vendor Can Access AP Approval URL Directly

| Field | Details |
|-------|---------|
| **Bug ID** | BUG-002 |
| **Title** | Access Control — Vendor role can access AP invoice queue via direct URL navigation |
| **Environment** | QA \| Firefox 127 \| macOS 14 \| Build 2.3.1 |
| **Severity** | Critical |
| **Priority** | P1 |
| **Reproducibility** | Always |
| **Preconditions** | Vendor V001 is logged in with role = Vendor. |
| **Steps to Reproduce** | 1. Log in as Vendor V001<br>2. In the address bar, navigate directly to: /ap/invoice-queue<br>3. Observe the page rendered |
